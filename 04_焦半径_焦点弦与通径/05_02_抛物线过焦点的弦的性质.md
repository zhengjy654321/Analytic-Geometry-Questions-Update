## 补充性质 ⑬–㉒（原稿 ①–⑫ 之外的常考结论）

记号同原稿：$AB$ 是 $y^2 = 2px$ 的焦点弦，$A(x_1, y_1)$，$B(x_2, y_2)$，倾斜角 $\theta$，$A_1$、$B_1$ 是 $A$、$B$ 在准线上的射影，$M$ 是 $AB$ 中点。全部从原稿 ⑦ 的 $y_1y_2 = -p^2$、$x_1x_2 = \frac{p^2}{4}$ 推出。原稿 ⑪⑫（切线交于准线、互相垂直）的完整展开见第 3 节阿基米德三角形。

![⑬ A、O、B₁ 共线；⑭ ∠AOB 为钝角](images/05_02_collinear.svg)

**⑬ $A$、$O$、$B_1$ 三点共线**（同理 $B$、$O$、$A_1$ 共线）

$k_{OA} = \frac{y_1}{x_1} = \frac{2p}{y_1}$，$k_{OB_1} = \frac{y_2}{-\frac{p}{2}} = -\frac{2y_2}{p}$。由 $y_2 = -\frac{p^2}{y_1}$，$k_{OB_1} = \frac{2p}{y_1} = k_{OA}$，所以==共线==。反过来，过 $A$ 和原点的直线与准线的交点，其纵坐标等于 $B$ 的纵坐标，即 $BB_1 \parallel x$ 轴（2001 年全国卷经典题）。

**⑭ 数量积与斜率积**

$$\overrightarrow{OA} \cdot \overrightarrow{OB} = x_1x_2 + y_1y_2 = \frac{p^2}{4} - p^2 = -\frac{3}{4}p^2, \quad k_{OA} \cdot k_{OB} = \frac{y_1y_2}{x_1x_2} = -4$$

所以 ==$\angle AOB$ 恒为钝角==，$\triangle AOB$ 不可能是直角三角形（直角在 $O$）。

**⑮ 焦半径之积**：$|AF| \cdot |BF| = \frac{p}{1 - \cos \theta} \cdot \frac{p}{1 + \cos \theta} = \frac{p^2}{\sin^2\theta}$ = ==$\frac{p}{2}|AB|$==（由 ④ $|AB| = \frac{2p}{\sin^2\theta}$）。这和 ③ $\frac{1}{|AF|} + \frac{1}{|BF|} = \frac{2}{p}$ 是同一件事。

**⑯ 通径最短**：$|AB| = \frac{2p}{\sin^2\theta} \ge 2p$，==$\theta = 90^\circ$ 时最短，等于通径 $2p$==；$S_{\triangle AOB} = \frac{p^2}{2\sin \theta} \ge \frac{p^2}{2}$，也是通径时最小。

**⑰ 坐标和与中点轨迹**：设 $AB: x = my + \frac{p}{2}$（$m = \frac{1}{\tan \theta}$），则

$$y_1 + y_2 = 2pm, \quad x_1 + x_2 = m(y_1 + y_2) + p = 2pm^2 + p, \quad |AB| = x_1 + x_2 + p = 2p(1 + m^2)$$

中点 $M\left(pm^2 + \frac{p}{2}, \, pm\right)$，消去 $m$ 得==中点轨迹 $y^2 = p\left(x - \frac{p}{2}\right)$==（顶点在焦点的抛物线）。

![⑰ 焦点弦中点的轨迹](images/05_02_midpoint_locus.svg)

**⑱ 以焦半径、焦点弦为直径的圆**：原稿 ⑧ 已证「以 $AB$ 为直径的圆与准线相切」「以 $AF$ 为直径的圆与 $y$ 轴相切」；另外 ==以 $A_1B_1$ 为直径的圆过焦点 $F$，且与 $AB$ 相切于 $F$==（即原稿 ⑨⑩ 的合写：$\angle A_1FB_1 = 90^\circ$，$M'F \perp AB$）。

**推广到非焦点弦**：把焦点换成 $x$ 轴上任一点 $(m, 0)$，结论 $y_1y_2 = -2pm$、$x_1x_2 = m^2$ 仍然成立；$m = 2p$ 时 $OA \perp OB$。见下一条「直角弦与定点弦」。

**⑲ 两条互相垂直的焦点弦**：$AB \perp CD$，都过焦点，$AB$ 的倾斜角为 $\theta$，则 $CD$ 的倾斜角为 $\theta + 90^\circ$。由 ④，

$$\frac{1}{|AB|} + \frac{1}{|CD|} = \frac{\sin^2\theta}{2p} + \frac{\cos^2\theta}{2p} = \frac{1}{2p}$$

即 ==$\frac{1}{|AB|} + \frac{1}{|CD|} = \frac{1}{2p}$ 为定值==。推论：$|AB| + |CD| = 2p(|AB| + |CD|)\left(\frac{1}{|AB|} + \frac{1}{|CD|}\right) \ge 2p \cdot 4 = 8p$，==$|AB| + |CD|$ 的最小值为 $8p$==（$\theta = 45^\circ$ 时取到）；四边形 $ACBD$ 的面积 $\frac{1}{2}|AB||CD| \ge 8p^2$。

![⑲ 两条垂直的焦点弦](images/05_02_perpendicular.svg)

**⑳ 焦点弦的中垂线交 $x$ 轴于 $G$，则 $|FG| = \frac{1}{2}|AB|$**

设 $M$ 为 $AB$ 中点，$\angle MFG = \theta$（取锐角），$MG \perp AB$，所以 $|FG| = \frac{|MF|}{\cos \theta}$。而 $|MF| = \frac{|AF| - |BF|}{2} = \frac{1}{2}\left(\frac{p}{1 - \cos \theta} - \frac{p}{1 + \cos \theta}\right) = \frac{p\cos \theta}{\sin^2\theta}$，于是

$$|FG| = \frac{p}{\sin^2\theta} = \frac{1}{2}|AB|$$

这个结论对椭圆、双曲线同样成立，写成统一形式 ==$\frac{|FG|}{|AB|} = \frac{e}{2}$==（抛物线 $e = 1$），小题求离心率时可以直接用。

![⑳ |FG| = |AB|/2](images/05_02_fg.svg)

**㉑ 弦过 $N(m, 0)$，则 $x$ 轴平分 $\angle AMB$，其中 $M(-m, 0)$**

设 $AB$：$x = ty + m$，由推广结论 $y_1y_2 = -2pm$，$y_1 + y_2 = 2pt$。

$$k_{MA} + k_{MB} = \frac{y_1}{x_1 + m} + \frac{y_2}{x_2 + m} = \frac{y_1(ty_2 + 2m) + y_2(ty_1 + 2m)}{(x_1 + m)(x_2 + m)} = \frac{2ty_1y_2 + 2m(y_1 + y_2)}{(x_1 + m)(x_2 + m)} = 0$$

所以 ==$\angle AMO = \angle BMO$==（$N$、$M$ 关于原点对称）。$m = \frac{p}{2}$ 时 $N$ 是焦点、$M$ 是准线与 $x$ 轴的交点 $K$：==过焦点的弦，$KF$ 平分 $\angle AKB$==。

![㉑ x 轴平分 ∠AMB](images/05_02_bisect.svg)

**㉒ 两个小结论**

- 从 $K\left(-\frac{p}{2}, 0\right)$ 向抛物线引两条切线，切线斜率为 $\pm 1$（与 $x$ 轴成 $45^\circ$），切点恰是通径的两个端点 $\left(\frac{p}{2}, \pm p\right)$。（由 ⑫ 切点弦过焦点，又关于 $x$ 轴对称，所以切点弦就是通径。）
- 开口向上的 $x^2 = 2py$，如果 $\theta$ 取焦点弦与 $x$ 轴的夹角，焦半径写成 $|AF| = \frac{p}{1 - \sin \theta}$、$|BF| = \frac{p}{1 + \sin \theta}$（长的用减，短的用加）；取与对称轴（$y$ 轴）的夹角时仍是 $\frac{p}{1 \mp \cos \theta}$。看清角是跟哪条轴的夹角。
